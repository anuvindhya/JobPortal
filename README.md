 Job Portal Web Application

 Project Description

The Job Portal is a web-based application developed using Python and Django. It connects job seekers with employers through a simple and user-friendly platform.

Job seekers can explore available job opportunities and apply for suitable positions. Employers can post job vacancies and manage job applications.

 Features

- User Registration and Login
- User Authentication
- Job Listings
- Search and View Job Opportunities
- Apply for Jobs
- Employer Job Posting
- Manage Job Applications
- Admin Management

Technologies Used

- **Backend:** Python, Django
- **Frontend:** HTML, CSS, Bootstrap, JavaScript
- **Database:** SQLite
- **Version Control:** Git and GitHub
